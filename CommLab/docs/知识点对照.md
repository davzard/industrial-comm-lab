# 知识点对照表

> 学习路线（每个知识点）→ CommLab 中对应的模块与章节。跑对应模块即可看到该知识点的可运行示例 + 自测。

## 第一阶段：基础

| 知识点 | 位置 | 演示内容 |
|---|---|---|
| 二进制/十六进制/字节数组 | M01 §1 | int↔byte[]↔hex 互转，`0x0001` 在内存里长什么样 |
| 数据类型转换 | M01 §2 | 16/32 位整数、浮点、字符串的字节表示；`BitConverter` 字节序陷阱 |
| 大小端 | M01 §3 | 大端/小端对比，`ByteUtils` 提供 `ToBigEndian/ToLittleEndian` |
| 校验和 | M01 §4 | 累加和、异或和，M02 帧的 SUM 字段就是它 |
| CRC16 | M01 §5 | 多项式 0xA001（Modbus），`Crc.Crc16Modbus` 全帧校验=0 的验证方法 |

## 第四阶段：Modbus（重点）

| 知识点 | 位置 | 演示内容 |
|---|---|---|
| 设备地址 | M04 §1 | RTU 从站地址 1~247；TCP 的 Unit ID |
| 功能码 | M04 §2 | 01/02/03/04 读，05/06 写，15/16 批量写 |
| 线圈/寄存器 | M04 §3 | 0~3 区：线圈/离散输入/保持/输入寄存器，bit vs 16bit |
| RTU 报文格式 | M04 §4 | 地址+功能码+数据+CRC16(LE)，逐字节打印 |
| CRC | M04 §4 | 全帧+CRC 再算一遍=0 的验证技巧 |
| MBAP 头 | M04 §5 | 事务号/协议号/长度/单元号，TCP 报文逐字段拆解 |
| 寄存器地址映射 | M04 §6 | 40001=保持寄存器 0 的编号偏移坑 |
| 异常码 | M04 §7 | 功能码|0x80+异常码，01 非法功能/02 非法地址/03 非法值/04 从站故障 |
