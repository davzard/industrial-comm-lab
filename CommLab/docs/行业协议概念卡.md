# 行业协议概念卡

> M09 配套资料。面试时不需要背细节，但每个协议要能说出：**它是什么、用在什么场景、上位机怎么对接、一句话关键词**。

## 1. CAN / CANopen

- **是什么**：CAN 是车载/工业现场总线（差分信号，抗干扰强，最长 12m~5km 视速率）；CANopen 是建立在 CAN 之上的应用层标准（DS301/DS303/DS306 等）。
- **场景**：电梯、电梯门机、电机驱动器、AGV、医疗设备、汽车。
- **上位机对接**：USB-CAN / PCI-CAN 卡 + 厂商 SDK（如 PCAN、ZLG 周立功、Kvaser）；或 CANopen 主站库（如 CANopenNode、SOEM 思路的开源栈）。
- **关键词**：
  - CAN 帧：标准帧 ID 11 位 / 扩展帧 29 位；数据段最多 8 字节（CAN FD 可到 64 字节）；CRC + 多重重试，**可靠性极高**；
  - 总线仲裁：ID 越小优先级越高，**线控与/显性-隐性**；
  - CANopen：对象字典(Object Dictionary) 参数化、节点 ID、PDO（周期数据）/ SDO（参数读写）/ HRT（心跳）/ EMERGENCY；
  - 上位机写参数走 SDO，周期数据看 PDO——和 Modbus 的"寄存器读写"思路类比。
- **面试一句话**："CAN 是物理层+数据链路层的现场总线，CANopen 是它的应用层标准；我们上位机通过 USB-CAN 卡，用 SDO 配参数、PDO 采周期数据。"

## 2. EtherCAT

- **是什么**：倍福(Beckhoff)主导的**周期实时以太网**协议，基于 IEC 61158。
- **场景**：伺服/运动控制、高速同步的多轴系统（机器视觉定位、缠绕机、印刷机）。
- **原理关键词**：
  - **FOU（Forward On Update）**：每个从站"边读边写边转发"——读自己那帧、把自己的数据写进去、立刻转发给下一个从站，整个环一圈延迟只有几微秒；
  - 主站是 PC 上的实时核（Windows 实时扩展 / Linux PREEMPT_RT），周期 100µs~1ms；
  - 数据模型：DC（分布式时钟）同步、过程数据（PDO 式周期）+ 配置数据；
  - 上位机侧用 **SOEM（Open Source EtherCAT Master）** 或倍福 TwinCAT 的 ADS 接口（上位机作为 ADS 客户端连 TwinCAT）。
- **面试一句话**："EtherCAT 是'处理-转发'的实时以太网，从站不缓存整帧，延迟微秒级；我们上位机要么用 SOEM 做主站，要么通过 ADS 连 TwinCAT 主站拿过程数据。"

## 3. PROFINET

- **是什么**：西门子主导的工业以太网标准（IEC 61158），PROFIBUS 的以太网继任者。
- **场景**：西门子 S7 控制器 + 分布式 IO/驱动器的工厂。
- **通信类型**：
  - **PROFINET CBA**（基于应用）：非实时，TCP/UDP，文件传输、S7 通信、OPC UA 都走这里；
  - **PROFINET RT**（实时）：周期数据，用 UDP + 自定义帧头，周期 1~100ms；
  - **PROFINET IRT**（改进实时）：网卡硬件时间戳，周期 <1ms，需要 IRT 网卡；
- **上位机对接**：上位机一般走 CBA（S7 协议读 PLC、OPC UA 读 PLC），周期过程数据由 PLC 侧处理，上位机不直接做 RT 主站（那是控制器的事）。
- **面试一句话**："PROFINET 分 CBA/RT/IRT 三档实时性；上位机一般走 CBA 层的 S7 或 OPC UA 通信，周期数据让 PLC 主站管。"

## 4. EtherNet/IP

- **是什么**：罗克韦尔(AB)主导的工业以太网，基于 **CIP（Common Industrial Protocol）**，IEC 61158 标准之一。
- **场景**：Allen-Bradley 控制器（ControlLogix/CompactLogix）的工厂。
- **通信方式**：
  - **Connected（连接型）**：先建连接（CIP 握手）再周期传数据，类似 TCP 的"连接"；
  - **Unconnected（无连接）**：点对点发，类似 UDP，适合低频读；
  - 底层：TCP 44818（Connected）/ UDP 2222（Unconnected）；
- **上位机对接**：
  - 开源 **Libplc3**（C 库，支持 AB/Rockwell）；
  - 或走 **OPC UA**（ControlLogix 5000 支持）；
  - 或厂商 DDE/OPC DA（老系统）。
- **面试一句话**："EtherNet/IP 的精髓是 CIP；Connected 连接型周期传、Unconnected 无连接点传；上位机用 Libplc3 或 OPC UA 对接。"

## 5. 机器人通信

- **是什么**：工业机器人（FANUC/ABB/KUKA/安川/国产埃斯顿等）与上位机（示教/监控/取数）的通信。
- **主流方式**：
  - **TCP 私有协议**：各厂商私有寄存器/变量映射（FANUC 的 FOCAS2 库、KUKA 的 KRL 变量、ABB 的 RAPID 变量）；
  - **OPC UA**：新机型普遍内置（FANUC CRX4、KUKA KR C5、ABB IRC5 都有 OPC UA 服务器）；
  - **数字量/模拟量 IO 映射**：机器人 IO 板 → 上位机，做握手信号（取料完成、放料完成、报警）；
  - **串口**：老机型 RS-232 传状态字。
- **典型交互**：上位机发"启动"信号 → 机器人执行取放程序 → 数字量"完成"拉高 → 上位机读工件号/质量数据 → 上报 MES。
- **面试一句话**："机器人通信本质是'握手 IO + 变量读写'；老机型走 TCP 私有协议+厂商库，新机型直接 OPC UA；关键是 IO 握手时序和报警处理。"

## 6. 工业相机 SDK

- **是什么**：机器视觉相机（海康/大恒/巴斯勒/FLIR）通过 SDK 取图、配参数、触发。
- **传输标准**：
  - **GigE Vision**：基于 UDP 的流媒体（图像数据走 UDP，控制走 TCP），标准协议，跨厂商；
  - **USB3 Vision**：USB3 高速取图，免 IP 配置；
  - **CameraLink / CoaXPress**：高速数字接口，配采集卡。
- **上位机对接**：
  - 厂商 SDK（海康 MVS / MvCameraControl SDK、大恒 DHDSP、Basler pylon）；
  - 或 **GenICam** 标准（SFNC 标准节点：曝光/增益/触发模式/触发源/像素格式）；
  - 取图模式：连续采集（回调）/ 软触发 / 硬件触发（外部 IO 信号）；
  - 图像数据是内存缓冲（像素格式 Mono8/Mono16/YUV 等），注意**缓冲池管理**和**丢帧检测**。
- **面试一句话**："工业相机走 GigE Vision(UDP 流) 或 USB3 Vision，用厂商 SDK 或 GenICam 标准节点配参数；上位机重点处理触发时序、缓冲池和丢帧。"

## 7. MQTT（详见 M08）

- 设备→云/MES 的轻量 Pub/Sub；QoS0/1/2、保留消息、遗嘱；
- 上位机角色：通常是**发布者**（把 PLC 数据发上去）+ 订阅者（收 MES 下发的指令）。

## 8. HTTP/REST（详见 M08）

- MES/ERP/设备云平台的对接方式；JSON + 状态码 + 超时 + 重试；
- 注意：**长连接场景别用 HTTP 轮询**（延迟高、服务器压力大），用 MQTT/WebSocket/长轮询。

## 9. MES（制造执行系统）

- **是什么**：管"工单→报工→追溯→质量"的车间层系统，位于 ERP（计划）和 PLC/设备（控制）之间。
- **上位机的角色**：MES 的**数据供应商**——把设备状态、产量、不良、工艺参数报给 MES；同时从 MES 拉工单/配方。
- **常见对接**：
  - REST API（主流，JSON）；
  - WebService/SOAP（老 MES）；
  - MQTT（设备云架构）；
  - 数据库直连（不推荐，耦合重，但老项目常见）。
- **关键业务**：
  - **报工**：一件一件报（扫码触发）或批量报；
  - **追溯**：工件码 ↔ 设备 ↔ 参数 ↔ 人员 的绑定；
  - **防错**：MES 校验工序顺序，错了不让开工。
- **面试一句话**："上位机是 MES 的数据供应商：REST 报工+拉工单，关键是报工时机（扫码/信号触发）、断线补报、追溯字段绑定。"

## 附：一张表总结

| 协议 | 层 | 实时性 | 上位机常用对接方式 | 典型场景 |
|---|---|---|---|---|
| CAN/CANopen | 现场总线 | 高(µs~ms) | USB-CAN 卡 + SDK，SDO/PDO | 电梯、AGV、电机 |
| EtherCAT | 实时以太网 | 极高(µs) | SOEM / TwinCAT ADS | 多轴运动控制 |
| PROFINET | 工业以太网 | 中~高(CBA/RT/IRT) | S7 协议 / OPC UA (CBA 层) | 西门子工厂 |
| EtherNet/IP | 工业以太网 | 中~高 | Libplc3 / OPC UA | 罗克韦尔工厂 |
| 机器人 | TCP/OPC UA/IO | 低(秒级) | 厂商库 / OPC UA / IO 握手 | 上下料、装配 |
| 工业相机 | UDP/USB | 高(帧级) | 厂商 SDK / GenICam | 视觉检测 |
| MQTT | 应用层 | 低(秒级) | MQTTnet 客户端 | 设备云、MES |
| HTTP/REST | 应用层 | 低(秒级) | HttpClient | MES/ERP 对接 |
